# TripReplay

[English](README.md) | 繁體中文

TripReplay 將您的行程、照片與影片，製作成以地圖呈現的動態旅行回顧，並匯出為影片。所有處理皆在您的裝置上完成。

> **狀態：** 設計階段，目前尚無可用版本。

## 規劃功能

- 建立依日期分組的行程，支援跨國及跨時區。
- 匯入照片與影片，並指派至各景點。
- 產生俯視地圖動態回顧：景點間逐段繪製路線、鏡頭拉近至各地點，並依序播放媒體。
- 以可拖曳的時間軸預覽，支援 16:9 與 9:16 畫面比例。
- 匯出為 MP4（1080p 或 720p，30 fps）。
- 出發前即可完成離線準備，旅途中預覽無需使用行動數據。
- 支援 Web、Windows、macOS、Linux、Android 及 iOS。

## 隱私

您的照片、影片、中繼資料與專案絕不離開您的裝置。無需帳號、無使用分析，亦無雲端處理。僅在取得公開地圖資源及您主動進行地點搜尋時使用網路，並提供完全離線模式。詳見[產品規格 §4](docs/zh-TW/specification.md#4-離線運作與隱私)。
