# 行為準則

[English](../../CODE_OF_CONDUCT.md) | 繁體中文

> 本文件為英文版之翻譯；如有歧異，以英文版為準。

## 我們的承諾

TripReplay 是對所有人開放的社群專案。無論背景、身分、經驗或使用語言為何，參與者皆應共同營造尊重、具建設性且免於騷擾的協作環境。

## 期望的行為

- 在所有溝通中保持尊重與體貼。
- 先假設對方出於善意，並在下結論前請對方說明。
- 給予及接受建設性的回饋，聚焦於工作本身而非個人。
- 接受以英文或繁體中文提出的貢獻與問題。
- 尊重他人隱私，包括可能出現在問題回報中的個人旅行資訊。

## 不可接受的行為

- 騷擾、恐嚇，或使用歧視性的言語或圖像。
- 人身攻擊、侮辱或蓄意挑釁的言論。
- 未經明確同意，公開他人的私人資訊，例如所在位置、照片或聯絡方式。
- 持續干擾討論。
- 其他在專業場合中可合理認定為不當的行為。

## 適用範圍

本準則適用於所有專案空間，包括 Issue、Pull Request、討論區及本專案營運的其他管道，亦適用於個人公開代表本專案的場合。

## 回報

如有行為方面的疑慮，請透過版本庫擁有者 GitHub 個人頁面所列的聯絡方式，私下向維護者回報。所有回報皆予保密處理，回報者不會因此遭受報復。

## 執行

維護者會審閱每一則回報，並可採取其認為適當的任何措施，包括警告、暫時限制或永久移出專案空間。未本於善意遵守本準則的維護者，可被解除其職務。
