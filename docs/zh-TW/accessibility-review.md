本審查依 [M3](roadmap.md#m3--10-發行準備階段-e) 的完成條件進行：鍵盤操作、螢幕閱讀器標籤、足夠的對比度，以及預覽的減少動態效果選項。

## 1. 方法

在 Chromium 中以正式建置版本檢查核心情境的每個畫面：旅行列表（空白及含一趟旅行）、已下載區域的「**地圖**」、工作區的每個分頁（「**行程**」、「**媒體**」、「**日記**」、「**音樂**」、「**主題**」）、匯入對話框及預覽。每個畫面都在淺色與深色配色下，以指令碼進行下列檢查：

- 測量每段可見文字與其實際背景的對比度（1.4.3），以及文字欄位邊框與周圍的對比度（1.4.11）；
- 列出所有沒有無障礙名稱的控制項（4.1.2）；
- 以 **Tab** 走訪畫面，記錄每個取得焦點的控制項是否顯示焦點指示（2.1.1、2.4.7）。

此外，也在 320 CSS 像素寬度下檢查是否出現水平捲動（1.4.10），並在開啟系統「減少動態效果」設定的情況下進行檢查。

## 2. 發現與修正

| # | 發現 | 準則 | 修正 |
|---|---|---|---|
| 1 | 深色配色下，強調色上的白色文字（主要按鈕、「**播放**」、景點編號）對比度僅 3.2:1 | 1.4.3 對比（最低） | 新增 `--color-on-accent` 設計變數：淺色配色為白色（5.8:1），深色配色為深色文字（5.4:1） |
| 2 | 文字欄位、日期欄位、搜尋框、景點選擇器及日記欄位的邊框，與周圍的對比度僅 1.3–1.5:1 | 1.4.11 非文字對比 | 這些邊框改用新的 `--color-field` 設計變數，兩種配色下皆至少 3.4:1 |
| 3 | 預覽只依照系統的「減少動態效果」設定，應用程式中沒有對應選項 | [1.0 定義 §6.3](release-1.0.md#63-易用性與無障礙)、2.3.3 | 預覽中新增「**減少動態效果**」按鈕。預設依照系統設定，並記錄於瀏覽器中 |
| 4 | 工作區分頁只能以 **Tab** 逐一到達，且未顯示的分頁指向不存在的面板 | 2.1.1 鍵盤、4.1.2 | 分頁改依 WAI-ARIA 分頁模式運作：只佔一個 Tab 停駐點，可使用方向鍵、**Home** 與 **End** |
| 5 | 「**媒體**」與「**日記**」中的影片縮圖，對螢幕閱讀器呈現為未命名的影片 | 4.1.2 名稱、角色、值 | 縮圖對輔助科技隱藏；每個項目由其文字命名 |

修正後，兩種配色下的所有畫面中，均無對比度低於 4.5:1 的文字（大型文字為 3:1）、低於 3:1 的欄位邊框，或沒有名稱的控制項。

## 3. 已符合標準的項目

- **鍵盤。** 核心情境的所有控制項都能以鍵盤依合理順序到達並操作，且有可見的焦點指示。日期欄位會以瀏覽器本身的醒目標示呈現取得焦點的部分。
- **拖曳有替代方式**（2.5.7）。可在時間軸上拖曳的照片長度、影片剪輯與音樂位置，也能透過「**媒體**」與「**音樂**」中的欄位設定。
- **播放。** 空白鍵可播放與暫停；播放位置滑桿有名稱，並會讀出時間，例如「0:12 / 1:30」。
- **狀態訊息**（4.1.3）。儲存、匯入、音樂、備份、還原及地圖下載的狀態，都透過狀態區域通知。
- **語言**（3.1.1）。頁面語言依介面語言設為 `en` 或 `zh-TW`。
- **重排**（1.4.10）。在 320 CSS 像素寬度下，旅行列表、工作區及「**地圖**」都不需要水平捲動。
- **動態效果。** 開啟「減少動態效果」時，鏡頭飛行與推近效果會以交叉淡化取代（[畫面設計 §6](ui-design.md#6-回顧內容)）。

## 4. 仍存在的限制

- **回顧本身是視覺內容。** 地圖、路線與標題繪製於畫布上，螢幕閱讀器無法讀取。相同的資訊可在「**行程**」、「**媒體**」與「**日記**」中以文字取得。
- **影片聲音沒有字幕。** 影片由使用者提供，本身不含字幕；改以使用者的日記備註作為字幕顯示。
