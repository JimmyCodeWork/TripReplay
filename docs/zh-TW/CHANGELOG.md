## [Unreleased]

### 新增

- 依區域從 Overture Maps 下載地圖，下載前顯示大小，可暫停、續傳、驗證、更新及刪除；亦可開啟裝置上既有的地圖檔。
- 完全在裝置上搜尋已下載地圖中的地點，並支援貼上座標或地圖連結。
- 旅行：建立、重新命名、複製、刪除，以及以專案包備份與還原。
- 依日期分組景點的行程，以及日記：每個景點一篇日記，每張照片或每段影片一則備註。
- 匯入媒體時依 GPS 位置與拍攝時間建議景點，確認後才會加入。
- 回顧預覽：路線動畫、鏡頭移動、標題、附說明文字的照片與影片、影片聲音與背景音樂、16:9 與 9:16，以及全螢幕播放。
- 在時間軸上編輯：照片長度、影片剪輯，以及音樂的移動與剪輯，可拖曳，也可為選取的段落以秒數輸入；整趟旅行的開場、移動、景點標題與結尾長度；時間軸上方的時間刻度。
- 時間軸上方的上一天、上一段、下一段與下一天按鈕，並會選取該段落。
- 途中照片：勾選「途中」的照片會在畫線前往其景點時以小卡片顯示，並延長該段移動；照片有位置資訊時，路線會經過拍攝地點。
- 影片匯出：在裝置上以 WebCodecs 將回顧連同聲音匯出為 1080p 或 720p 的 MP4 檔，並儲存到您選擇的位置（[ADR 0009](adr/0009-export-in-1-0.md)）。
- 工作區的「**復原**」與「**重做**」按鈕，以及時間軸的「**重設時間間隔**」。
- 可單獨設定某個景點的標題長度與移動到該景點的長度，取代整趟設定與因文字而自動延長的長度。
- 匯入的檔案會放到「媒體」分頁中所選取的景點，建議的景點只要一鍵即可改用。
- 日記也可一次顯示一天；「媒體」分頁可從依日期分組的清單選擇景點、以拖曳排序媒體，並可從「編輯」將照片或影片移到其他景點。
- 縮小影片：「**匯入時縮小影片**」（開啟前保持關閉），以及縮小旅行或備份時的「**也縮小影片**」，會將影片重新編碼為 1080p，聲音不變；「**縮小照片**」改為「**縮小媒體**」。
- 備份可選「**縮小照片**」；匯出影片時可選「**檔案大小**」並顯示預估大小。
- 縮小照片：「媒體」分頁的「**匯入時縮小照片**」會以長邊最多 2560 像素儲存照片（關閉前保持開啟）；旅行上的「**縮小照片**」可縮小已匯入旅行的照片。
- Web 應用程式由 `main` 以 GitHub Pages 發布；`launch/` 中的啟動程式（`pnpm start`）可在電腦上以 `http://localhost:4173` 提供服務。
- 透過 WebMCP 為瀏覽器的 AI 代理提供工具，須在旅行中按下「**AI 代理**」才會開啟：代理可讀取開啟中旅行的文字，並新增與修改景點、日記、每日開場文字、備註與時間設定，每項變更都可復原。
- 點選的項目在周圍展開或收起時會留在原處，頁面不再跳動。
- 行程可一次顯示一天、以拖曳排序，並展開所選景點的操作，可開啟其媒體與日記，或將它複製到指定位置。
- 回顧較長時可縮放時間軸，並以總覽列捲動。
- 地圖區域擴充至 29 個國家與地區，地圖對話框可依國家篩選，熱門國家列於前面，並提供收藏、已下載，以及裝置目前位置所在的區域（位置只在裝置上使用）。
- 可將景點複製到其他日期，適用於連住多晚的飯店或再次經過的車站；地點搜尋會優先列出已在本行程中的地點。
- 回顧中前往每個新一天的第一個景點時，畫面會如入夜般變暗，並顯示「第 N 天」與日期，以及在日記中為這天寫的開場文字。
- 回顧中在景點標題下方，以明體搭配柔和光暈逐行顯示該景點的日記，並停留足夠的時間以便閱讀；照片與影片的備註以相同字型顯示於畫面下緣。
- 主題：經典、夜間與直式。
- 可安裝且無需連線即可啟動的 Web 應用程式，其內容安全政策僅允許連線至地圖下載來源。
- 每次發行皆附上由實際打包的程式碼產生的 SBOM 與第三方授權聲明。
- 預覽中的「減少動態效果」選項，預設依照系統設定；工作區分頁可使用方向鍵操作；強調色上的文字與欄位邊框之對比度，在淺色與深色配色下皆符合 WCAG 2.2 AA。
- 以 Capacitor 從同一個頁面建置的 Android 應用程式（APK）：備份會儲存到您選擇的位置，其函式庫亦須通過專屬的授權門檻（[ADR 0008](adr/0008-android-in-1-0.md)）。
