## [Unreleased]

### 新增

- 在「媒體」分頁選取縮圖，即可以視窗大小預覽照片或影片（影片會立即播放剪輯後的片段），並可用「**上一個**」與「**下一個**」（或方向鍵）瀏覽該景點的媒體。
- 「**地圖**」會建議在 Wi-Fi 環境下載；Android 裝置使用行動數據時，確認下載的畫面會先建議改用 Wi-Fi。
- 「設定」新增「**關於**」，顯示版本與「**檢查更新**」，只在選取時檢查：網頁版會載入新版本並提供「**重新載入**」；Android 與 Windows 應用程式會向 GitHub 查詢發行版本，有新版時連到下載頁面。
- 在 iPhone 與 iPad 上，畫面會避開狀態列與螢幕圓角，不再被頂部的模糊區域蓋住標題與上方按鈕。
- 尚未下載任何地圖時，每次開啟旅行都會顯示「**尚未下載地圖**」，可選「**稍後下載**」在沒有地圖的情況下繼續，或選「**前往下載**」前往「地圖」。
- 「設定」新增「**儲存空間**」：顯示 TripReplay 已使用的空間與瀏覽器允許的上限、地圖與旅行的照片、影片和音樂各占多少，以及瀏覽器是否可能自行清除資料。
- 日文：TripReplay 的畫面現在提供英文、繁體中文與日文。可在「**設定 → 語言**」中選擇，或與以往一樣依瀏覽器的語言；變更會立即生效。README 與 Windows 安裝檔也提供這三種語言。
- MCP 設定改名為「**開啟 MCP Server**」，所屬分組改為「**代理工具**」，說明也以淺白文字交代代理工具能看到與能做的事：只有在您開啟並輸入配對碼後，才能看到開啟中旅行的文字，且所有變更都可以復原。
- 每個版本附上 Windows 安裝檔 `tripreplay-windows-…-setup.exe`：以 Microsoft Edge WebView2 執行的 Windows 10 與 11 版 TripReplay，以目前使用者身分安裝、不需系統管理員權限，並有自己的旅行資料。安裝檔尚未簽章，因此執行前 SmartScreen 會發出警告（[ADR 0016](../adr/0016-windows-application.md)）。
- 從桌面拖曳到工作區的照片與影片，會與「**匯入媒體**」一樣匯入所選景點；拖入的音訊檔則加入為音樂。
- 「媒體」分頁也加入與日記分頁相同的「**上一個景點**」與「**下一個景點**」按鈕。
- 「直式」主題更名為「**藍海**」，且不再將回顧切換為 9:16：所有主題的直式或橫式都只由畫面比例決定。「媒體」分頁中，影片的起點與終點放不下時會換行，不再壓到「**編輯**」；「**途中**」勾選框也與文字對齊。
- 預覽可選擇 0.5×、1×、1.5× 或 2× 的播放速度，影片與音樂的聲音也以相同速度播放。寬螢幕上，側邊面板可用滾輪獨立捲動，預覽因此保持在畫面中。
- 「日記」分頁改為一次顯示一個景點，可從依天分組的清單或「**上一個景點**」、「**下一個景點**」選擇，日記很長時捲動不再卡頓；可在設定的「**日記顯示方式**」改為一次一天。
- 景點標記在鏡頭抵達時才出現，不再於開場就顯示。設定中的「**?**」與「**!**」改為以應用程式配色開啟小對話框，在深色模式下也清晰可讀。播放中進入全螢幕時，會先為較大的畫面讀取地圖再繼續。
- 瀏覽器的匯出對話框在「**儲存影片**」旁新增「**下載**」。瀏覽器未顯示儲存對話框就立即關閉時，儲存匯出影片或備份不再毫無反應，而是改為下載檔案。
- 新的一天成為回顧中的獨立段落，位於前往其第一個景點的移動之前：顯示天數、日期與開場文字時，鏡頭與路線停在原處，之後才開始移動。天數與開場文字不再延長移動時間。
- 回顧會等新一天的文字完整出現後，鏡頭與路線才開始移動；正在繪出的路段及其景點會畫在先前的路線與標記之上，線頭並加上箭頭。所有標題（旅行標題、有或沒有日記的景點標題、新的一天及摘要）背後都襯以相同的柔和暗色光暈。
- 拉遠到縮放層級 7 以下時只繪製全球概覽，消除區域圖磚邊緣的接縫（[ADR 0015](adr/0015-overview-alone-when-zoomed-out.md)）。
- 頁首的「**設定**」集中了適用於所有旅行的選項，分為播放與地圖、匯入及 AI 代理三組；設定旁的小「**?**」提供說明，「**!**」標示須先知道的事項。「**減少動態效果**」由預覽下方移至此處，瀏覽器 AI 代理與 MCP 的開關則由工作區上方列移至此處。
- 「**先讀取地圖**」（預設開啟，可在設定中關閉）：「**播放**」會先讀取鏡頭路徑上的地圖並顯示進度，長距離的鏡頭移動不再出現空白或畫到一半的區域；預設只在景點附近 25 公里內讀取詳細地圖，更遠處只讀取全球概覽，速度較快（[ADR 0014](adr/0014-load-map-before-playing.md)）。全球概覽改以區域的陸地而非區域範圍遮住，區域圖磚尚未畫出的地方會顯示概覽。
- 「地圖」中的「**全球概覽**」：全世界少數幾個縮放層級的地圖，約 60 MB，畫在已下載的區域下方，鏡頭飛越區域之間時不再出現空白背景（[ADR 0013](../adr/0013-world-overview.md)）；已載入的地圖圖磚會保留所有縮放層級。
- 依區域從 Overture Maps 下載地圖，下載前顯示大小，可暫停、續傳、驗證、更新及刪除；亦可開啟裝置上既有的地圖檔。
- 完全在裝置上搜尋已下載地圖中的地點，並支援貼上座標或地圖連結。
- 旅行：建立、重新命名、複製、刪除，以及以專案包備份與還原。
- 依日期分組景點的行程，以及日記：每個景點一篇日記，每張照片或每段影片一則備註。
- 匯入媒體時依 GPS 位置與拍攝時間建議景點，確認後才會加入。
- 回顧預覽：路線動畫、鏡頭移動、標題、附說明文字的照片與影片、影片聲音與背景音樂、16:9 與 9:16，以及全螢幕播放。
- 在時間軸上編輯：照片長度、影片剪輯，以及音樂的移動與剪輯，可拖曳，也可為選取的段落以秒數輸入；整趟旅行的開場、移動、景點標題與結尾長度；時間軸上方的時間刻度。
- 時間軸上方的上一天、上一段、下一段與下一天按鈕，並會選取該段落。
- 途中照片：勾選「途中」的照片會在畫線前往其景點時以小卡片顯示，並延長該段移動；照片有位置資訊時，路線會經過拍攝地點。
- 影片匯出：在裝置上以 WebCodecs 將回顧連同聲音匯出為 1080p 或 720p 的 MP4 檔，並儲存到您選擇的位置（[ADR 0009](adr/0009-export-in-1-0.md)）。
- 工作區的「**復原**」與「**重做**」按鈕，以及時間軸的「**重設時間間隔**」。
- 可單獨設定某個景點的標題長度與移動到該景點的長度，取代整趟設定與因文字而自動延長的長度。
- 匯入的檔案會放到「媒體」分頁中所選取的景點，建議的景點只要一鍵即可改用。
- 日記也可一次顯示一天；「媒體」分頁可從依日期分組的清單選擇景點、以拖曳排序媒體，並可從「編輯」將照片或影片移到其他景點。
- 時間軸可用與行程相同的天數按鈕一次顯示一天。
- 預覽下方的「**只看行程**」可播放不含照片與影片的回顧以確認行程；全螢幕時不再顯示時間軸，控制列因此會留在畫面上。
- TripReplay MCP server（`apps/mcp`），供 Claude Desktop 與 Claude Code 等代理使用；TripReplay 透過「**MCP**」（開啟前保持關閉）與配對碼連線到同一台電腦上的 server。
- 縮小影片：「**匯入時縮小影片**」（開啟前保持關閉），以及縮小旅行或備份時的「**也縮小影片**」，會將影片重新編碼為 1080p，聲音不變；「**縮小照片**」改為「**縮小媒體**」。
- 備份可選「**縮小照片**」；匯出影片時可選「**檔案大小**」並顯示預估大小。
- 縮小照片：「媒體」分頁的「**匯入時縮小照片**」會以長邊最多 2560 像素儲存照片（關閉前保持開啟）；旅行上的「**縮小照片**」可縮小已匯入旅行的照片。
- Web 應用程式由 `main` 以 GitHub Pages 發布；`launch/` 中的啟動程式（`pnpm start`）可在電腦上以 `http://localhost:4173` 提供服務。
- 透過 WebMCP 為瀏覽器的 AI 代理提供工具，須在旅行中按下「**AI 代理**」才會開啟：代理可讀取開啟中旅行的文字，並新增與修改景點、日記、每日開場文字、備註與時間設定，每項變更都可復原。
- 點選的項目在周圍展開或收起時會留在原處，頁面不再跳動。
- 行程可一次顯示一天、以拖曳排序，並展開所選景點的操作，可開啟其媒體與日記，或將它複製到指定位置。
- 回顧較長時可縮放時間軸，並以總覽列捲動。
- 地圖區域擴充至 29 個國家與地區，地圖對話框可依國家篩選，熱門國家列於前面，並提供收藏、已下載，以及裝置目前位置所在的區域（位置只在裝置上使用）。
- 可將景點複製到其他日期，適用於連住多晚的飯店或再次經過的車站；地點搜尋會優先列出已在本行程中的地點。
- 回顧中前往每個新一天的第一個景點時，畫面會如入夜般變暗，並顯示「第 N 天」與日期，以及在日記中為這天寫的開場文字。
- 回顧中在景點標題下方，以明體搭配柔和光暈逐行顯示該景點的日記，並停留足夠的時間以便閱讀；照片與影片的備註以相同字型顯示於畫面下緣。
- 主題：經典、夜間與直式。
- 可安裝且無需連線即可啟動的 Web 應用程式，其內容安全政策僅允許連線至地圖下載來源。
- 每次發行皆附上由實際打包的程式碼產生的 SBOM 與第三方授權聲明。
- 預覽中的「減少動態效果」選項，預設依照系統設定；工作區分頁可使用方向鍵操作；強調色上的文字與欄位邊框之對比度，在淺色與深色配色下皆符合 WCAG 2.2 AA。
- 以 Capacitor 從同一個頁面建置的 Android 應用程式（APK）：備份會儲存到您選擇的位置，其函式庫亦須通過專屬的授權門檻（[ADR 0008](adr/0008-android-in-1-0.md)）。
