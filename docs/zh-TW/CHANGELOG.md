## [Unreleased]

### 新增

- 依區域從 Overture Maps 下載地圖，下載前顯示大小，可暫停、續傳、驗證、更新及刪除；亦可開啟裝置上既有的地圖檔。
- 完全在裝置上搜尋已下載地圖中的地點，並支援貼上座標或地圖連結。
- 旅行：建立、重新命名、複製、刪除，以及以專案包備份與還原。
- 依日期分組景點的行程，以及日記：每個景點一篇日記，每張照片或每段影片一則備註。
- 匯入媒體時依 GPS 位置與拍攝時間建議景點，確認後才會加入。
- 回顧預覽：路線動畫、鏡頭移動、標題、附說明文字的照片與影片、影片聲音與背景音樂、16:9 與 9:16，以及全螢幕播放。
- 在時間軸上編輯：照片長度、影片剪輯，以及音樂的移動與剪輯。
- 主題：經典、夜間與直式。
- 可安裝且無需連線即可啟動的 Web 應用程式，其內容安全政策僅允許連線至地圖下載來源。
- 每次發行皆附上由實際打包的程式碼產生的 SBOM 與第三方授權聲明。
