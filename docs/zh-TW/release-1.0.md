本文件定義 TripReplay 1.0 的範圍與品質標準。[產品規格](specification.md)描述長期的產品樣貌；兩者不同之處，以本文件界定 1.0 實際發行的內容。相關決策記錄於 [ADR 0004](adr/0004-web-first-release.md)。

標示為*提議*的數值為工作目標，將於技術驗證期間（路線圖 M1）確認。

## 1. 摘要

透過 TripReplay 1.0，旅行者可以開啟網站，以景點清單規劃或重建一趟旅行，加入該趟旅行的照片、影片與音樂，並匯出地圖動態回顧的 MP4 影片——全程在自己的裝置上完成，可連線或離線使用，介面提供英文與繁體中文。

## 2. 目標使用者與核心情境

**目標使用者：** 想以短片分享旅程，但不想將媒體上傳至雲端服務、也不具備影片剪輯技能的個人旅行者。

**核心情境：**

1. 出發前或旅行結束後，使用者建立旅行，並透過搜尋或標點加入景點。
2. 離線前，使用者下載該旅行的離線包。
3. 旅行結束後，使用者匯入照片與影片；TripReplay 依 GPS 資料與拍攝時間為每個項目建議景點，由使用者確認或修正。
4. 使用者選擇主題與背景音樂，預覽回顧，並調整時長與裁剪。
5. 使用者匯出 MP4，並透過作業系統或任何 App 分享。

## 4. 功能

### 4.1 核心功能

| 領域 | 1.0 功能 |
|---|---|
| 旅行 | 建立、開啟、重新命名、複製及刪除旅行；顯示各旅行的儲存空間用量 |
| 行程 | 依日期分組景點；地點搜尋與手動標點；調整順序；名稱與描述；支援多日、跨國及跨越換日線 |
| 媒體 | 從裝置匯入照片與影片；指派至景點；調整順序；裁剪影片；設定照片時長、旋轉及填滿方式；調整片段音量 |
| 預覽 | 在可拖曳的時間軸上呈現路線動畫、鏡頭移動、景點標題及媒體；支援 16:9 與 9:16 |
| 匯出 | MP4（H.264），1080p 或 720p，30 fps；保留原始音訊；顯示進度、可取消，並提供具體的錯誤說明 |
| 離線 | 每趟旅行一個離線包，提供容量估算、暫停、續傳、驗證及更新；無網路連線時仍可完整預覽與匯出 |
| 專案 | 自動儲存；可將旅行備份為專案包並還原 |
| 語言 | 整個介面與文件皆提供英文及繁體中文 |

### 4.2 1.0 必要的其他功能

| 功能 | 1.0 功能 |
|---|---|
| 媒體自動配對 | 依每個匯入項目的 GPS 座標與拍攝時間建議景點，並可修正時區。建議一律顯示供使用者確認，絕不自動套用。缺少中繼資料的項目留待手動指派。 |
| 背景音樂 | 從裝置匯入一或多個音訊檔；放置於時間軸上；與原始音訊混音，支援淡入、淡出，並在有聲片段播放時自動降低音樂音量。音樂的使用權由使用者自行負責。不隨附任何音樂。 |
| 主題 | 從隨附主題中選擇，設定地圖樣式、路線顏色，以及標題與字幕樣式。*提議：* 上線時提供三款主題，其中一款適用於 9:16。 |

### 4.3 不在 1.0 範圍內

安裝版應用程式；雲端同步與帳號；協作；逐路段道路導航；即時 GPS 追蹤；衛星影像與 3D 建築；4K 與 HDR 輸出；多軌剪輯；靜態圖片匯出；範本或主題商店；隨附音樂。

## 5. 地圖資料

| 面向 | 1.0 做法 |
|---|---|
| 來源 | OpenStreetMap 資料，由本專案處理為 PMTiles 格式的向量圖磚 |
| 託管 | 由本專案營運的靜態檔案託管，以 HTTP Range Request 提供圖磚；不需要應用程式伺服器 |
| 授權 | 資料以 ODbL-1.0 授權；於執行期下載，絕不隨附於發行成品（[相依套件授權政策 §2](license-policy.md#2-適用範圍)）。依該授權對衍生資料庫的要求，本專案以 ODbL 公開所處理的圖磚。 |
| 來源標示 | 於地圖畫面顯示「© OpenStreetMap contributors」，並渲染至匯出影片中 |
| 離線包 | 於裝置上依旅行時間軸所需的圖磚範圍下載並建立 |
| 隱私 | 圖磚請求會透露使用者檢視的區域。託管設定為不記錄請求，隱私聲明中會說明此點；使用者亦可手動標點，並於準備完成後完全離線作業 |
| 更新 | *提議：* 每季重新產生圖磚；既有離線包在使用者更新前仍可正常使用 |
| 標籤 | 資料中有繁體中文名稱時優先使用，否則退回當地名稱 |

## 6. 品質標準

1.0 是可公開推薦的成品：從未與本專案聯繫過的人，也能自行安裝、使用並得到良好的成果。

### 6.1 功能

[產品規格 §9](specification.md#9-驗收標準與測試) 的所有驗收情境，皆須於承諾支援的瀏覽器上通過，並以下列*提議*的參考目標為準：

| 指標 | 目標 |
|---|---|
| 參考旅行 | 10 個景點、50 張照片、10 段影片，輸出 3 分鐘 |
| 預覽 | 於參考筆電上達 30 fps；拖曳時間軸時，停頓不超過 1 秒 |
| 匯出時間 | 於參考筆電上以 1080p 匯出，耗時不超過影片長度的兩倍 |
| 影片最長長度 | 10 分鐘 |
| 媒體量 | 每趟旅行 10 GB，且不致耗盡記憶體 |

### 6.2 可靠性

- 編輯、匯入或匯出期間，若瀏覽器當機、分頁關閉或裝置休眠，皆不遺失資料。
- 中斷的匯出絕不會產生被呈現為完成的檔案。
- 瀏覽器清除儲存空間時能被偵測、說明，並可從專案包備份復原。

### 6.3 易用性與無障礙

- 首次使用者在易用性測試中，無需外部協助即可完成核心情境。
- 每個畫面皆可以鍵盤操作、具備螢幕閱讀器標籤，並符合 WCAG 2.2 AA 對比度要求。
- 預覽提供減少動態效果的選項。

### 6.4 文件與支援

- 英文與繁體中文的使用者指南，涵蓋核心情境、離線準備及備份。
- 隱私聲明，確切說明應用程式發出哪些網路請求。
- 已知問題清單與瀏覽器支援表，並隨每次發行更新。
- Issue 範本與安全政策已就位（已完成）。

### 6.5 發行工程

- 採用語意化版本；`1.0.0` 自 `main` 建立標籤，並附上變更紀錄。
- 通過授權發行門檻，且應用程式提供 `THIRD-PARTY-NOTICES`（[相依套件授權政策 §6](license-policy.md#6-發行門檻)）。
- 部署的網站使用 HTTPS，並以內容安全政策（CSP）限制網路存取僅限本專案的圖磚託管及地點搜尋供應商。
