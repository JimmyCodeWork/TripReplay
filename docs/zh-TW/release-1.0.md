本文件定義 TripReplay 1.0 的範圍與品質標準。[產品規格](specification.md)描述長期的產品樣貌；兩者不同之處，以本文件界定 1.0 實際發行的內容。相關決策記錄於 [ADR 0004](adr/0004-web-first-release.md) 及 [ADR 0006](adr/0006-local-only-operation.md)。

標示為*提議*的數值為工作目標，將於技術驗證期間（路線圖 M1）確認。

## 1. 摘要

TripReplay 1.0 交付完整的畫面體驗。旅行者可以開啟網站，以景點清單規劃或重建一趟旅行，加入該趟旅行的照片、影片與音樂，並在瀏覽器中觀看地圖動態回顧——全程在自己的裝置上完成，介面提供英文與繁體中文。

所有功能皆在裝置上執行。首次使用前，使用者按一個按鈕下載所需區域的地圖；之後編輯、地點搜尋與預覽皆不需要網路連線。本專案不營運任何伺服器。

將回顧匯出為影片檔，將於 1.0 之後的版本推出（§4.3）。

## 2. 目標使用者與核心情境

**目標使用者：** 想以地圖動態回顧重溫並展示旅程，但不想將媒體上傳至雲端服務、也不具備影片剪輯技能的個人旅行者。

**核心情境：**

1. 出發前或旅行結束後，使用者下載所需區域的地圖、建立旅行，並透過搜尋已下載的地圖、標點或貼上座標加入景點。
2. 旅行結束後，使用者匯入照片與影片；TripReplay 依 GPS 資料與拍攝時間為每個項目建議景點，由使用者確認或修正。
3. 使用者選擇主題與背景音樂，預覽回顧，並調整時長與裁剪。
4. 使用者以全螢幕播放回顧，例如展示給家人與朋友觀看。

| | 1.0 |

## 4. 功能

### 4.1 核心功能

| 領域 | 1.0 功能 |
|---|---|
| 旅行 | 建立、開啟、重新命名、複製及刪除旅行；顯示各旅行的儲存空間用量 |
| 地圖下載 | 選擇區域，按一個按鈕下載其地圖；下載前顯示大小，下載後顯示已用空間；可暫停、續傳、驗證、更新及刪除 |
| 行程 | 依日期分組景點；於已下載的地圖中搜尋地名，完全在裝置上進行；手動標點；貼上座標或地圖連結（例如來自 Google Maps）；調整順序；名稱與描述；支援多日、跨國及跨越換日線 |
| 媒體 | 從裝置匯入照片與影片；指派至景點；調整順序；裁剪影片；設定照片時長、旋轉及填滿方式；調整片段音量 |
| 預覽 | 在可拖曳的時間軸上呈現路線動畫、鏡頭移動、景點標題及媒體；支援 16:9 與 9:16；可全螢幕播放並輸出聲音 |
| 專案 | 自動儲存；可將旅行備份為專案包並還原 |
| 語言 | 整個介面與文件皆提供英文及繁體中文 |

### 4.2 1.0 必要的其他功能

| 功能 | 1.0 功能 |
|---|---|
| 媒體自動配對 | 依每個匯入項目的 GPS 座標與拍攝時間建議景點，並可修正時區。建議一律顯示供使用者確認，絕不自動套用。缺少中繼資料的項目留待手動指派。 |
| 背景音樂 | 從裝置匯入一或多個音訊檔；放置於時間軸上；於預覽中與原始音訊混音播放，支援淡入、淡出，並在有聲片段播放時自動降低音樂音量。音樂的使用權由使用者自行負責。不隨附任何音樂。 |
| 主題 | 從隨附主題中選擇，設定地圖樣式、路線顏色，以及標題與字幕樣式。*提議：* 上線時提供三款主題，其中一款適用於 9:16。 |

### 4.3 1.0 之後

| 版本 | 功能 |
|---|---|
| 1.0 之後的下一個版本 | MP4 匯出（H.264，1080p 與 720p，30 fps），含原始音訊與背景音樂 |
| 之後 | Windows、macOS、Linux、Android 及 iOS 安裝版 |

1.0 的架構不得妨礙上述功能：預覽由[產品規格 §7](specification.md#7-預覽與影片管線) 的確定性 `renderAt(timeUs)` 驅動，使匯出能渲染相同的影格；地圖資源僅從已下載的地圖檔讀取。

### 4.4 不在規劃中

雲端同步與帳號；協作；逐路段道路導航；即時 GPS 追蹤；衛星影像與 3D 建築；4K 與 HDR 輸出；多軌剪輯；靜態圖片匯出；範本或主題商店；隨附音樂。

## 5. 地圖資料

| 面向 | 1.0 做法 |
|---|---|
| 來源 | 衍生自 OpenStreetMap 的 PMTiles 格式區域地圖檔，從非本專案營運的公開來源下載。應用程式亦可開啟使用者已有的地圖檔。來源為待決事項（§7） |
| 下載 | 由使用者選擇區域；檔案以 HTTP 範圍請求分段下載、驗證，並以[技術驗證 S6](spikes/s6-web-storage.md) 的匯入協定儲存於裝置上 |
| 使用 | 渲染與地點搜尋僅讀取已下載的檔案。編輯或預覽期間不發出任何地圖或搜尋請求 |
| 授權 | 資料以 ODbL-1.0 授權；由使用者下載，絕不隨附於發行成品（[相依套件授權政策 §2](license-policy.md#2-適用範圍)） |
| 來源標示 | 於地圖畫面及全螢幕播放時顯示「© OpenStreetMap contributors」 |
| 隱私 | 下載來源可得知下載了哪些區域，但無從得知旅行、景點、搜尋或媒體。隱私聲明中會說明此點 |
| 更新 | 有較新的地圖時，應用程式會提示；是否更新由使用者決定 |
| 標籤 | 資料中有繁體中文名稱時優先使用，否則退回當地名稱 |

## 6. 品質標準

1.0 是可公開推薦的成品：從未與本專案聯繫過的人，也能自行開啟、使用並得到良好的成果。

### 6.1 功能

[產品規格 §9](specification.md#9-驗收標準與測試) 中適用於編輯與預覽的驗收情境，皆須於所有支援的瀏覽器上通過，並以下列*提議*的參考目標為準：

| 指標 | 目標 |
|---|---|
| 參考旅行 | 10 個景點、50 張照片、10 段影片，回顧長度 3 分鐘 |
| 預覽 | 於參考筆電上達 30 fps；拖曳時間軸時，停頓不超過 1 秒 |
| 啟動 | 於參考筆電上開啟參考旅行，3 秒內顯示第一個畫面 |
| 媒體量 | 每趟旅行 10 GB，且不致耗盡記憶體 |

### 6.2 可靠性

- 編輯或匯入期間，若瀏覽器當機、分頁關閉或裝置休眠，皆不遺失資料。
- 瀏覽器清除儲存空間時能被偵測、說明，並可從專案包備份復原。
- 尚未下載地圖的區域絕不阻擋編輯；預覽會顯示明確的替代畫面，並提供下載。
- 中斷的地圖下載不會留下被使用的不完整地圖，且可以續傳。

### 6.3 易用性與無障礙

- 首次使用者在易用性測試中，無需外部協助即可完成核心情境。
- 每個畫面皆可以鍵盤操作、具備螢幕閱讀器標籤，並符合 WCAG 2.2 AA 對比度要求。
- 預覽提供減少動態效果的選項。

### 6.4 文件與支援

- 英文與繁體中文的使用者指南，涵蓋核心情境及備份。
- 隱私聲明，確切說明應用程式發出哪些網路請求。
- 已知問題清單與瀏覽器支援表，並隨每次發行更新。
- Issue 範本與安全政策已就位（已完成）。

### 6.5 發行工程

- 採用語意化版本；`1.0.0` 自 `main` 建立標籤，並附上變更紀錄。
- 通過授權發行門檻，且應用程式提供 `THIRD-PARTY-NOTICES`（[相依套件授權政策 §6](license-policy.md#6-發行門檻)）。
- 部署的網站使用 HTTPS，並以內容安全政策（CSP）限制網路存取僅限地圖下載來源。

| 事項 | 決定時點 |

| 參考筆電與手機型號 | M1 |

| 公開網站的網域名稱 | M3 |
