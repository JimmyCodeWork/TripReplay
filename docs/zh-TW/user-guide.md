TripReplay 會把行程、照片與影片製作成旅行的動態地圖回顧。所有處理都在您的瀏覽器中、在您的裝置上完成：不需要帳號，您的旅行與媒體也不會上傳到任何地方（[隱私聲明](privacy.md)）。

本指南依照核心情境說明：下載地圖、規劃行程、加入照片與影片、選擇外觀與音樂，然後播放回顧。最後幾節說明備份與儲存空間。

## 1. 開始之前

- **瀏覽器。** 請使用最新版本的 Chrome、Edge、Safari 或 Firefox 開啟 [https://jimmycodework.github.io/TripReplay/](https://jimmycodework.github.io/TripReplay/)，該網址一律提供最新版本。各瀏覽器之間的差異請見[瀏覽器支援](browser-support.md)。
- **Android 應用程式。** 在 Android 手機或平板（Android 7.0 以上）上，也可以改為安裝 TripReplay 應用程式：從專案的[發行版本](https://github.com/JimmyCodeWork/TripReplay/releases)下載 `tripreplay-android-….apk`，開啟後允許瀏覽器或檔案管理員安裝。請透過 Google Play 將 Android System WebView 保持在最新版本。應用程式的使用方式與網站相同，差異列於下文；它有自己的旅行資料，若要在兩者之間移動旅行，請使用備份（§9）。
- **安裝（選用）。** 瀏覽器可以將 TripReplay 安裝為應用程式，例如使用 Chrome 或 Edge 網址列中的安裝按鈕，或在 iPhone 與 iPad 的 Safari 中選擇「**分享 → 加入主畫面**」。安裝後的應用程式會在桌面或主畫面上建立圖示，按一下即可在自己的視窗中開啟，沒有網路連線也能啟動。
- **在自己的電腦上執行，不經網站（選用）。** 安裝 [Node.js](https://nodejs.org/) 24 以上版本並取得一份[原始碼](https://github.com/JimmyCodeWork/TripReplay)後，在 Windows 上按兩下 `launch/TripReplay.cmd`，在 macOS 上按兩下 `launch/TripReplay.command`，或在 Linux 上執行 `launch/start.sh`。它會建置 TripReplay（首次啟動時也會安裝所需套件），在 `http://localhost:4173` 提供服務並以瀏覽器開啟；使用 TripReplay 期間請保持該視窗開啟。您也可以從該處將它安裝為應用程式，安裝後即使關閉該視窗也能啟動；再次執行啟動程式即可更新。瀏覽器會依網址分別保存旅行，因此在 `localhost` 建立的旅行不會出現在網站上，反之亦然；請用備份（§9）移動旅行。
- **儲存空間。** 地圖與媒體由瀏覽器儲存在本裝置上。一個區域的地圖約需數百 MB，照片與影片則佔用與原檔相同的空間。每次下載與匯入前，TripReplay 都會先確認可用空間。
- **離線使用。** 只有第一次開啟 TripReplay 與下載地圖時需要網路連線。之後所有功能都能離線使用，包括地點搜尋。

## 2. 下載地圖

地圖用來顯示路線，也讓您搜尋地點。行程經過的每個區域只需下載一次。

1. 選取上方的「**地圖**」。
2. 找到區域，例如「**日本・關西**」，然後選取「**下載**」。列表預設顯示熱門國家；可在「**國家或地區**」中選擇其他國家、「**收藏**」或「**已下載**」。「**使用目前位置**」會列出您所在的區域；位置資訊只在本裝置上使用，Android 應用程式會先詢問權限。選取區域旁的 ☆ 即可加入收藏。
3. TripReplay 會顯示檔案大小與本裝置的可用空間。再次選取「**下載**」以確認。
4. 等到區域顯示「**已就緒**」。下載期間可以「**暫停**」與「**繼續**」，也可以繼續編輯旅行。連線中斷時，下載會從中斷處接續。

「**地圖**」中還可以：

- 「**開啟地圖檔**」加入本裝置上已有的 PMTiles 地圖檔，例如從另一台電腦複製過來的檔案。
- 「**檢查更新**」尋找較新的地圖。有更新的區域會顯示「**更新**」；新地圖就緒前，目前的地圖仍可繼續使用。
- 「**刪除**」移除不再需要的區域。您的旅行不受影響；該區域內的景點在預覽中改以純色背景顯示。

## 3. 規劃行程

1. 選取上方的「**旅行**」，再選取「**建立第一趟旅行**」（或「**新增旅行**」）。旅行會在工作區中開啟；之後可在旅行列表中重新命名。
2. 在「**行程**」中，將「**新景點的日期**」設為要加入的那一天。
3. 在搜尋框輸入地點名稱並選擇結果，景點便會加入該日。
   - 除了名稱，也可以貼上座標（例如 `34.9949, 135.785`），或從 Google 地圖、Apple 地圖、OpenStreetMap 或 Bing 地圖複製的連結。`maps.app.goo.gl` 這類短網址必須連線才能解讀；請先開啟它，再複製完整連結。
4. 為每個景點重複上述步驟。景點會依日期分組。

選取景點時，預覽會移至該景點，並顯示其操作：「**媒體**」與「**日記**」會開啟該分頁並定位到此景點；「**複製**」、「**重新命名景點**」、「**移除景點**」、「**上移**」與「**下移**」可變更景點。要調整順序時，選取標題旁的「**排序**」，拖曳景點的把手（⠿）移到別處（也可移到其他天），再選取「**完成**」；平時不顯示把手，避免誤觸而移動景點。行程有多天時，「**第 1 天**」、「**第 2 天**」等按鈕可一次只顯示一天；「**全部**」會一起顯示，選擇某一天也會把「**新景點的日期**」設為那天。

重複造訪的地點，例如連住多晚的飯店或再次經過的車站，不必重新搜尋：

- 選取景點後按「**複製**」，選擇再次造訪的「**日期**」，以及要「**放在**」那天最前面或某個景點之後。同一天預設放在原景點之後，其他天預設放在最後一個景點之後。副本不含原景點的日記。
- 或在搜尋框輸入名稱：已在本行程中的地點會列在最前面，並標示「**本行程**」。

變更會自動儲存；儲存完成後工作區會顯示「**已儲存**」。工作區上方的「**復原**」與「**重做**」可撤銷上一個變更或再次執行；**Ctrl+Z** 與 **Ctrl+Shift+Z** 也有相同效果（Mac 上以 **⌘** 取代 **Ctrl**）。

在旅行列表中，每趟旅行都可以開啟、重新命名、建立副本、備份及刪除。

## 4. 加入照片與影片

請先加入景點；每張照片與每段影片都屬於一個景點。

1. 開啟「**媒體**」分頁，選取「**匯入媒體**」，然後選擇照片與影片。
2. TripReplay 會讀取每個檔案的拍攝時間與 GPS 位置，並建議景點：
   - 「**依位置**」：依檔案的 GPS 位置，選擇當天最近的景點；
   - 「**依日期**」：檔案沒有位置資訊時，選擇拍攝當天的第一個景點。
3. 檢查建議結果。需要時改選其他景點，再選取「**接受**」或「**全部接受**」。檔案會放到「**媒體**」分頁中所選取的景點；若某個檔案的時間或位置建議了其他景點，選取「**改用建議**」即可改放到該景點。
4. 時間以旅行的時區顯示。若相機的時鐘設在其他時區，請選取「**變更**」並選擇正確的時區，建議結果會隨之更新。
5. 選取「**加入 … 個檔案**」完成匯入。

「**媒體**」分頁景點清單上方的「**匯入時縮小照片**」會以長邊最多 2560 像素儲存每張照片，在回顧中依然清晰，通常只占原本五分之一到十分之一的空間。在您關閉之前，此選項保持開啟。您裝置上的原始檔案不會變更，拍攝時間與位置也會保存在旅行中。若要縮小已匯入旅行的照片，請在「**旅行**」中選取該趟旅行的「**縮小照片**」，確認照片數量與所占空間後再確定。此動作無法在 TripReplay 中復原，若想在旅行中保留原尺寸照片，請先備份（§9）。

旅行中已有的檔案會被辨識出來，不會重複加入。照片與影片會複製到瀏覽器的儲存空間，因此之後可以移動或刪除原檔；但為防瀏覽器的儲存空間遭到清除，請保留原檔或備份（§9）。

在「**媒體**」分頁中，用「**景點**」清單選擇要查看哪個景點的照片與影片；清單依日期分組。要調整順序時，選取「**排序**」，拖曳照片或影片的把手（⠿），再選取「**完成**」。每一項也可以：

- 選取「**編輯**」，以「**上移**」與「**下移**」調整順序、以「**移到…**」移到其他景點（例如匯入時放錯了景點），或「**從景點移除**」；
- 設定照片顯示的「**秒數**」；
- 為前往景點途中拍攝的照片（例如在火車上拍的）勾選「**途中**」：畫線前往該景點時，會以小卡片顯示照片，移動時間也會延長到足以顯示所有途中照片。照片有位置資訊時，路線會經過拍攝地點，因此沿著鐵路拍的幾張照片就能描繪出路程。請依拍攝順序排列；
- 以「**從（秒）**」與「**到（秒）**」剪輯影片，並設定其「**音量**」。

## 5. 寫日記

「**日記**」分頁是這趟旅行的日記。可以為每一天寫一句開場文字，在回顧中這天開始時顯示，例如「搭首班新幹線前往京都」；為每個景點寫下當時發生的事；也可以為每張照片或每段影片加上簡短備註。行程較長時，可用「**第 1 天**」、「**第 2 天**」等按鈕一次只顯示一天。

- 回顧前往這天第一個景點時，開場文字會顯示在「第 2 天」與日期下方，移動時間也會延長到足以閱讀。第一天的開場文字會在前往第一個景點時顯示。

- 景點的日記會在回顧中顯示於景點名稱下方，最多三行（約 80 個字），並以如印刷日記般的明體逐行浮現。景點標題會停留較久，以便閱讀。
- 照片與影片的備註會在畫面出現後不久，顯示於畫面下緣，最多兩行。
- 離開欄位時或按 **Ctrl+Enter**（Mac 上為 **⌘+Enter**）時，內容便會儲存。

### 與瀏覽器的 AI 代理一起撰寫

部分電腦版瀏覽器內建 AI 代理。若您的瀏覽器會向網站提供其工具介面（WebMCP），旅行上方會出現「**AI 代理**」按鈕。選取它即可讓代理處理開啟中的旅行；再選取一次即停止。在您開啟之前，此功能都會保持關閉。

接著您可以請代理，例如依照您的筆記加入某一天的景點、以您的風格撰寫日記或照片說明，或為每個景點取較短的名稱。代理會讀取旅行的文字，並以與介面相同的步驟修改，因此每項變更都會立即呈現，也可以用「**復原**」撤銷。代理看不到您的照片與影片，也無法刪除任何內容或匯入檔案。

代理讀取的內容會傳送給它，通常也會傳送到其背後的服務（[隱私權聲明 §3](privacy.md#3-瀏覽器的-ai-代理)），因此請只在您願意與其分享的旅行開啟「**AI 代理**」。Android 應用程式沒有此按鈕。

## 6. 加入音樂

1. 開啟「**音樂**」分頁，選取「**加入音樂**」，然後選擇一個或多個音訊檔，例如 MP3、M4A 或 WAV。
2. 為每首音樂設定「**開始時間（秒）**」、「**淡入（秒）**」、「**淡出（秒）**」及「**音量**」。
3. 開啟「**有聲影片播放時降低音樂**」後，影片播放自身聲音時，音樂音量會降低。

請只使用您有權使用的音樂，公開播放回顧時更須注意。

## 7. 選擇主題與畫面比例

- 「**主題**」分頁提供「**經典**」（淺色地圖、深色路線）、「**夜間**」（深色地圖、發光路線）及「**直式**」（大標題置頂、媒體在下）。選擇「**直式**」時，回顧也會切換為 9:16。
- 在預覽下方選擇 **16:9**（適合螢幕與電視）或 **9:16**（適合手機）。

## 8. 預覽與播放

右側的預覽隨時顯示目前的回顧。

- 「**播放**」與「**暫停**」，或在沒有按鈕或欄位取得焦點時按空白鍵。
- 拖曳「**播放位置**」滑桿，或在滑桿上使用方向鍵，即可在回顧中移動。
- 滑桿下方的長條顯示回顧的各個段落：開場、移動、景點標題、照片、影片及結尾。選取某個段落即可跳至該處。
- 長條上方標示時間刻度。
- 長條上方的「**上一天**」、「**上一段**」、「**下一段**」與「**下一天**」會移到該段落並選取它，比點選細窄的區段更容易。
- 「**重設時間間隔**」會將開場、移動、景點標題、結尾及每張照片恢復為預設長度。影片剪輯與音樂維持不變，選取「**復原**」即可取回原本的長度。
- 回顧較長、段落變得很細時，可選取長條上方的「**+**」放大，最多放大到約 5 秒佔滿寬度；選取「**−**」可再次看到更多內容。放大後的長條可左右捲動：直接滑動長條，或拖曳下方總覽列中的視窗。回顧播放時，長條會跟著播放位置移動。
- 選取某個段落後，可在時間軸下方的欄位以秒數編輯：照片的長度、影片的起點與終點、音樂的開始時間，或開場、移動、景點標題及結尾的長度。開場、移動、標題與結尾的長度套用到整趟旅行；有日記的景點若需要更多閱讀時間，其標題會停留較久。景點標題或移動到景點時，可用「**此景點標題（秒）**」與「**移動到此景點（秒）**」只設定該景點的長度，不再自動延長（途中照片除外，一律保有其顯示時間）；選取「**改回整趟設定**」即可恢復。選取「**關閉**」即可隱藏欄位。
- 在時間軸上，也可以拖曳照片的右緣調整長度、拖曳影片的兩端進行剪輯，以及拖曳音樂調整位置。這些變更也能透過「**媒體**」與「**音樂**」分頁中的欄位完成。
- 「**減少動態效果**」會以交叉淡化取代鏡頭飛行與縮放。預設依照系統的「減少動態效果」設定，TripReplay 會在此瀏覽器中記住您的選擇。
- 「**全螢幕**」以整個螢幕播放回顧，例如播放給親友觀看。按 **Escape** 離開全螢幕。在 Android 應用程式中，它會填滿應用程式視窗；再次選取「**全螢幕**」即可離開。

若已下載的地圖都不包含您的景點，預覽會加以提示，並將回顧繪製於主題的背景上；請在「**地圖**」中下載該區域（§2）以顯示地圖。

### 匯出影片

要保存或分享回顧，請選取預覽下方的「**匯出影片**」。

1. 選擇「**1080p（較清晰）**」或「**720p（較快、檔案較小）**」。對話框會說明您的裝置將產生的格式。
2. 選取「**開始匯出**」，並讓 TripReplay 保持開啟且在前景直到完成；應用程式切到背景時匯出會停止。每一格都要等待地圖繪製完成，因此數分鐘的回顧可能需要數分鐘才能匯出。
3. 選取「**儲存影片**」並選擇存放位置。在 Android 應用程式中會開啟系統的儲存畫面。

影片完全在您的裝置上製作，不會上傳任何資料。

## 9. 備份與還原

瀏覽器可能清除已儲存的資料，例如裝置空間不足時，或在 Safari 中某個網站一段時間未使用後（[瀏覽器支援](browser-support.md)）。請備份您在意的旅行。

- **備份。** 在「**旅行**」中，選取旅行的「**備份**」。TripReplay 會儲存一個 `.tripreplay` 檔，內含旅行、日記、音樂及所有照片與影片。Chrome、Edge 與 Android 應用程式會詢問儲存位置；其他瀏覽器則會存到下載資料夾。
- **還原。** 選取「**還原備份**」並選擇 `.tripreplay` 檔。若本裝置上已有這趟旅行，可以選擇「**還原為副本**」；現有的旅行不會變更。

備份也可以用來把旅行移到另一台裝置或另一個瀏覽器：在一處備份，在另一處還原。備份不包含地圖；請在新裝置上重新下載。

## 10. 鍵盤操作

所有功能都能以鍵盤完成。**Tab** 與 **Shift+Tab** 在控制項之間移動，**Enter** 或空白鍵執行選取，方向鍵可切換分頁及調整滑桿。

| 按鍵 | 位置 | 動作 |
|---|---|---|
| 空白鍵 | 工作區中沒有按鈕或欄位取得焦點時，以及播放位置滑桿上 | 播放或暫停 |
| Ctrl+Z、Ctrl+Shift+Z | 工作區，文字欄位以外 | 復原、重做 |
| Ctrl+Enter | 日記 | 儲存內容 |
| Escape | 匯入對話框、全螢幕 | 關閉、離開全螢幕 |

Mac 上請以 **⌘** 取代 **Ctrl**。
