# 0013. 可下載、畫在區域下方的全球概覽

## 背景

回顧地圖只會顯示使用者下載的區域（[ADR 0006](0006-local-only-operation.md)）。鏡頭拉遠以飛越區域之間時，例如從臺灣的桃園機場飛到九州的福岡，畫面大部分位於所有區域之外，只會畫出純色背景，看起來像破圖。加大圖磚快取沒有幫助，因為這些地方根本沒有圖磚。

評估過填補這些地方的做法：

- **隨應用程式附帶世界地圖。** Natural Earth 的公有領域聲明不在素材白名單內（[ADR 0002](0002-public-domain-and-data-licenses.md)），且附帶地圖會使每次安裝增加數十 MB。
- **從 Overture Maps 下載全球概覽**，來源與授權皆與區域相同。
- **下載更大的區域。** 一趟航程可能跨越數個國家，使用者必須完整下載每一個。

Overture 各主題全世界的大小（依最高縮放層級）：z0–3 約 61 MB（base 51 MB、divisions 10 MB、無 transportation）、z0–4 約 335 MB、z0–5 約 873 MB。

## 決策

1. **「地圖」中的「全球概覽」。** 地圖對話框在區域上方提供「**全球概覽**」：全世界 Overture 主題的縮放層級 0 至 3，約 61 MB。它和區域一樣可以下載、暫停、繼續、更新與刪除，但沒有星號，也不算作涵蓋景點的區域。
2. **畫在區域下方。** 就緒後，每張回顧地圖都會以獨立來源繪製它，並在縮放層級 3 以上放大：以陸地色呈現陸地，另有水域與國界。區域本身的地圖畫在其上方；在每個區域的範圍內，以陸地色填滿，遮住概覽較粗略的海岸線。
3. **未下載任何區域時單獨使用。** 沒有任何區域時，概覽本身即作為地圖繪製。
4. **較大的圖磚快取。** 地圖會保留所有縮放層級已載入的圖磚（16 個層級，最多 1024 塊），讓播放過一次的回顧再次播放時不必重新等待。

## 考慮過的替代方案

- **附帶世界地圖。** 不採用：其資料授權不在白名單內，且會使每次安裝變大。
- **更多縮放層級。** 未選用：z0–4 大了五倍以上，而區域之間的飛行很少貼近區域外的地面。
- **沿鏡頭路徑預先載入圖磚。** 試過後放棄：空白處是沒有圖磚的地方，不是圖磚尚未載入。

## 影響

- 下載約 61 MB 後，區域之間的飛行會顯示陸地、海洋與國界，而不是空白背景。
- 在區域之外，概覽較為粗略：海岸線經過簡化，也沒有道路與地名。
- 概覽與區域從同一個 Overture Maps 主機下載；[隱私權聲明](../privacy.md)已涵蓋。
