TripReplay 只在您的裝置上處理您的旅行、照片、影片、日記與音樂。它沒有帳號、沒有分析、沒有廣告，也沒有自己的伺服器。本聲明列出應用程式發出的每一項網路請求，以及它在您的裝置上儲存的內容。

## 1. 網路請求

應用程式只會發出下列請求，不會有其他請求。建置後的頁面帶有內容安全政策（Content Security Policy），讓瀏覽器阻擋任何其他目的地（[發行流程 §1](releasing.md#1-建置產出)）。

| 時機 | 目的地 | 傳送的內容 | 目的地可得知的資訊 |
|---|---|---|---|
| 開啟 TripReplay 時，以及瀏覽器檢查新版本時 | 您開啟 TripReplay 的網站 | 一般的應用程式檔案請求（HTML、指令碼、樣式、圖示、`sw.js`） | 有人開啟了應用程式，以及一般的請求資訊：IP 位址、時間與瀏覽器（使用者代理） |
| 在「**地圖**」中選取「**下載**」、「**更新**」或「**檢查更新**」時 | Overture Maps 的公開儲存空間 `overturemaps-extras-us-west-2.s3.us-west-2.amazonaws.com`（架設於 Amazon Web Services） | 可用地圖版本的清單請求，以及涵蓋所選區域的地圖封存檔片段之 HTTP 範圍請求 | 您的 IP 位址、時間與瀏覽器，以及下載了哪些區域（因為所請求的片段對應這些區域） |

具體而言：

- **旅行資料不會離開裝置。** 旅行、景點、日記內容、照片、影片、音樂、其中繼資料（例如 GPS 位置與拍攝時間）及備份都不會傳送到任何地方。
- **地點搜尋在裝置上進行**，使用已下載的地圖。搜尋內容、貼上的座標與地圖連結都不會傳送到任何地方；只有其服務才能解讀的地圖短網址不會被開啟。
- **不會連線至其他服務**：不使用外部字型、地圖樣式、遙測、當機回報，也不向其他服務檢查更新。
- 應用程式安裝或快取後，會從裝置上的副本啟動。有網路連線時，瀏覽器仍會向網站檢查 `sw.js` 是否有新版本。

網站營運者與 Overture Maps 自行決定記錄哪些資訊及保存多久，TripReplay 無法控制。TripReplay 本身不設定任何 Cookie。

## 2. 儲存在您裝置上的資料

TripReplay 儲存的所有資料，都由您的瀏覽器依您開啟它的網站保存，可透過瀏覽器的網站資料設定移除。

| 儲存方式 | 內容 |
|---|---|
| IndexedDB | 旅行（行程、日記、設定）及已下載地圖的紀錄 |
| 來源私有檔案系統（Origin Private File System） | 地圖檔，以及您加入的照片、影片與音樂之副本 |
| 快取儲存空間（Cache Storage） | 應用程式本身的檔案，讓它能離線啟動 |
| 本機儲存空間（Local Storage） | 您在預覽中對「減少動態效果」的選擇 |

瀏覽器可能清除這些資料，例如裝置空間不足時（[瀏覽器支援 §3](browser-support.md#3-已知問題)）。請備份想保留的旅行（[使用指南 §9](user-guide.md#9-備份與還原)）。

## 3. Android 應用程式

Android 應用程式（[ADR 0008](adr/0008-android-in-1-0.md)）包含相同的應用程式，發出的地圖請求也相同。差異如下：

- 其檔案已在套件中，因此不會向任何網站發出請求，也不會檢查新版本。新版本隨新的 APK 提供。
- 它只向 Android 要求網路存取權限，供地圖下載使用。
- 它將資料儲存在裝置上應用程式自己的儲存空間，與任何瀏覽器分開。解除安裝應用程式時，這些資料會一併刪除。
- 應用程式已關閉 Android 的自動備份，旅行與媒體不會被複製到 Google 帳戶。請改用 TripReplay 本身的備份功能（§2）。

## 4. 您選擇的檔案

TripReplay 只讀取您選擇的檔案：照片、影片、音樂、地圖檔及備份檔，並將其複製到本裝置上的儲存空間。您儲存的備份檔包含整趟旅行及其媒體，也包含媒體的 GPS 位置；請只分享給可以看到這些資訊的人。

## 5. 連結

「**開放原始碼授權**」連結開啟的是應用程式本身的檔案。本文件中的連結（例如問題追蹤）會前往其他網站，這些網站各有其隱私政策。

## 6. 變更與聯絡方式

本聲明的變更會記錄於[變更記錄](CHANGELOG.md)。回報隱私問題，請依照[安全政策](SECURITY.md)。
